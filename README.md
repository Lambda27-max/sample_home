# sample_home

家具配置を試行錯誤できるシンプルなブラウザアプリです。部屋の寸法と家具サイズを入力して、ドラッグ＆ドロップでレイアウトを組み合わせられます。

## 使い方

1. `index.html` をブラウザで開きます。
2. 左ペイン「間取り生成 & 保存」のテキストエリアに部屋リストJSONを貼り付け、「部屋JSONを反映」でSVG図面を生成します（「サンプル読込」で玄関＋廊下付き2LDK例が入ります）。  
   入力例:
   ```json
   {
     "rooms": [
       { "name": "LDK", "type": "living", "width": 400, "depth": 260, "tatami": 12, "priority": "南", "access": "corridor" },
       { "name": "洋室A", "type": "bedroom", "width": 280, "depth": 200, "tatami": 6, "priority": "東", "access": "corridor" },
       { "name": "洋室B", "type": "bedroom", "width": 260, "depth": 180, "tatami": 5, "priority": "西", "access": "corridor" },
       { "name": "洗面", "type": "wash", "width": 140, "depth": 120, "tatami": 0.5, "priority": "北", "access": "corridor" },
       { "name": "浴室", "type": "bath", "width": 160, "depth": 140, "tatami": 0.75, "priority": "北", "access": "corridor" },
       { "name": "トイレ", "type": "toilet", "width": 90, "depth": 130, "tatami": 0.5, "priority": "北", "access": "corridor" }
     ]
   }
   ```
   玄関/廊下の自動生成ON/OFF、廊下幅、玄関位置（南/東/西）をフォームで調整できます。自動生成時は廊下に接続するドアが作図されます。
3. 家具フォームで「家具名・カテゴリ・幅/奥行・向き」を入力し追加します。家具はSVG上をドラッグ＆ドロップで移動、回転ボタンで90°回転、グリッドスナップ（5cm/10cm切替）付きです。壁外に出ると赤、他家具と重なると黄で表示します。
4. 「ローカル保存/復元」で現在の間取りJSONと家具配置・扉情報を localStorage に保存/読込できます。

インストールやビルドは不要で、スタンドアロンの HTML だけで動作します。

プレビュー用にローカルサーバーを立ち上げる場合は、リポジトリ直下で以下を実行し、ブラウザで表示してください。

```bash
python3 -m http.server 8080
```

`http://localhost:8080/index.html` にアクセスするとトップページが確認できます。

## 不動産チラシ風・家具配置アプリへの拡張要件（提案）

### 入力項目（想定）
- 物件属性: 間取りタイプ（1K/1DK/1LDK/2LDK など）、方位（北/北東/…）、階数、築年、面積、天井高。
- 寸法系: 外形寸法（幅・奥行）、各室寸法、廊下幅、階段幅、梁・柱寸法、畳数（換算・実測）、スケール（cm/pixel or cm/1ユニット）。
- 建具・設備: 玄関ドア、室内ドア（開き/引き）、窓（掃き出し/腰窓/スリット）、バルコニー位置・奥行、キッチン・洗面・浴室・トイレ・収納・CL/WIC、室内機/配管スペース。
- 家具: 名前、幅、奥行、高さ、回転可否、カテゴリ（ベッド/ソファ/テーブル等）、スナップ可否、色/アイコン。
- 仕上げ・注記: 寸法線表示ON/OFF、方位マーク表示、凡例表示、注記テキスト、備考欄。

### 画面構成（ワイヤー案）
- **左ペイン: 入力フォーム**  
  - 物件設定（間取りタイプ、外形寸法、方位）  
  - 部屋追加/編集（名前、サイズ、床仕上げ、畳数換算）  
  - 建具・設備の追加（ドア/窓/設備/バルコニー）  
  - 家具ライブラリ（プリセット＋カスタム）
- **右ペイン: キャンバス**  
  - SVG/Canvas で平面図描画  
  - ズーム・パン、方位アイコン、寸法線ON/OFF  
  - 家具のドラッグ＆ドロップ、スナップ、衝突警告  
  - 凡例/注記レイヤー表示切替

### 描画ルール（初期）
- スケール: 1px = 1cm 相当（ズームあり）。  
- 線: 外周壁 3px 濃灰、間仕切り 2px 灰、寸法線 1px 点線、建具記号はJIS風簡略。  
- 文字: 12–14px サンセリフ（Noto Sans JP）、室名は太字。寸法値は縮尺に応じて自動スケーリング。  
- 寸法線: 端点マーカー＋矢印、主要寸法（幅/奥行/開口幅）。  
- 方位: 右上に北マーク（N矢印）。  
- 建具記号: 開き戸は弧、引き戸は二重線、窓は二重線＋枠、バルコニーは網掛け。  
- 家具: 実寸スケール、枠線1px＋塗り、カテゴリ別アイコン。

### レイアウト自動生成の方針
- **MVP**: 間取りプリセット（1K/1DK/1LDKなど）の矩形エリアを定義し、外形寸法に合わせてスケール調整。建具・窓はプリセット位置に配置。  
- **v2**: シンプルなルールベース配置（例: 玄関→水回り→LDK→個室の並び、バルコニーは南・東優先）。開口衝突回避と廊下幅の最小確保。  
- **v3**: 制約充足 or 軽量最適化（面積配分、採光、家具配置の衝突最小化）。ユーザーの優先度（採光・収納量・動線）を重み付け。

### MVP範囲と段階的ロードマップ
- **MVP**  
  - プリセット間取りのSVG/Canvas描画（外形・壁・建具・窓・バルコニー・室名）。  
  - 家具アイコンの実寸配置とドラッグ＆スナップ（50cmグリッド）。  
  - JSONインポート/エクスポートで再現可能なデータモデル。
- **v2**  
  - 簡易自動レイアウト（ルールベース）、寸法線と凡例のON/OFF、方位マーク、畳数表示。  
  - 家具衝突判定と最小クリアランス警告。  
  - 建具/窓の編集UI、テクスチャ（床色・タイル感）。  
- **v3**  
  - 最適化/制約エンジンによる自動配置提案、複数案プレビュー。  
  - マルチレイヤー（電気/配管/家具）、PDF/PNG書き出し、URL共有。  
  - 協調編集、バージョン履歴。

### 実装方針（技術選定）
- 描画: SVG を推奨（寸法線・アイコン・テキストが扱いやすい）。大量要素時はCanvasレイヤー併用（背景グリッド・塗り）。  
- 状態管理: プレーンJSでも可だが、将来スケールを考慮し軽量シグナリング（例: Preact signals / Zustand）を検討。  
- スナップ/衝突判定: 50cmグリッドスナップ、AABB衝突で重なり検出、建具開閉角度の簡易チェック。  
- インポート/エクスポート: JSONスキーマ準拠で永続化、将来はURLクエリ圧縮も検討。  
- テスト: npm test は依存なし静的スモーク、CI環境では Playwright (npm run test:ci) で描画・DOMを検証。
