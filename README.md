# sample_home

家具配置を試行錯誤できるシンプルなブラウザアプリです。部屋の寸法と家具サイズを入力して、ドラッグ＆ドロップでレイアウトを組み合わせられます。

## 使い方

1. `index.html` をブラウザで開きます。
2. 「部屋の設定」で幅・奥行（cm）を入力し、更新します。
3. 「家具を追加」で名前とサイズを入力し、追加します。
4. キャンバス上の家具カードをドラッグして配置を調整します。グリッドは 50cm ピッチです。
5. 不要になった家具はリストの「削除」から取り除けます。

インストールやビルドは不要で、スタンドアロンの HTML だけで動作します。

プレビュー用にローカルサーバーを立ち上げる場合は、リポジトリ直下で以下を実行し、ブラウザで表示してください。

```bash
python3 -m http.server 8080
```

`http://localhost:8080/index.html` にアクセスするとトップページが確認できます。
